The organization (**CloudSecure SaaS Pvt. Ltd.**) is a fictional company created solely for educational and portfolio purposes.

The vendor risk assessment, risk register, ISO/IEC 27001 control mapping, executive dashboard, and recommendations were developed for academic learning and practical Governance, Risk, and Compliance (GRC) implementation.

---

# 2. Introduction

This project demonstrates the implementation of a **Third-Party Vendor Risk Assessment** framework for CloudSecure SaaS Pvt. Ltd. based on **ISO/IEC 27001:2022**.

The objective of the project was to identify vendor-related security risks, evaluate their business impact, prioritize them using a risk scoring methodology, map risks to ISO/IEC 27001 Annex A controls, and provide practical mitigation strategies.

The project includes vendor risk identification, risk scoring, ISO control mapping, executive reporting, and governance recommendations for improving third-party security management.

# 4. Activities Performed

## 4.1 Conducted Vendor Risk Assessment

Performed a structured assessment of third-party vendor risks affecting CloudSecure SaaS Pvt. Ltd.

The assessment evaluated vendors based on security controls, compliance requirements, access management, data protection, and operational resilience.

---

## 4.2 Developed Vendor Risk Register

Prepared a comprehensive vendor risk register containing **12 identified risks** across multiple security domains.

Each risk includes:

- Risk ID
- Vendor Name
- Risk Category
- Risk Description
- Likelihood
- Business Impact
- Risk Score
- Risk Level
- Risk Owner
- Recommended Mitigation
- ISO/IEC 27001 Control Reference

---

## 4.3 Performed Risk Scoring

Created a standardized **Likelihood × Impact (1–5)** risk scoring matrix to prioritize vendor risks.

Risk levels include:

- Critical
- High
- Medium
- Low

The scoring model supports effective decision-making by identifying high-priority risks requiring immediate attention.

---

## 4.4 Performed ISO/IEC 27001:2022 Control Mapping

Mapped every identified vendor risk to applicable **ISO/IEC 27001:2022 Annex A** controls.

Each mapping includes:

- Risk ID
- ISO Control Reference
- Control Description
- Control Category
- Implementation Guidance

---

# 7. Recommendations

Based on this Vendor Risk Assessment, I recommend:

1. Enforce Multi-Factor Authentication (MFA) for all privileged vendor accounts.
2. Implement Role-Based Access Control (RBAC).
3. Conduct periodic user access reviews.
4. Continuously monitor third-party vendors.
5. Strengthen vendor security requirements through contracts.
6. Align vendor security controls with ISO/IEC 27001:2022.
7. Perform regular vendor security assessments.
8. Conduct vendor security awareness training.
9. Monitor vendor risks using executive dashboards.
10. Continuously review and update the vendor risk register.
